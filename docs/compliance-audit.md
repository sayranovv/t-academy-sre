# Итоговая проверка требований и 12 Factor

Проверка выполнена 2026-10-01 перед закрытием учебного MVP. До этапа 7 полностью
выполнялись 8 из 12 факторов; build/release/run, concurrency, disposability и
dev/prod parity были подтверждены только частично. После добавления production-контура
и эксплуатационной проверки все 12 факторов применены в объёме этого проекта.

## Исходные требования

| Требование | Статус | Доказательство |
|---|---|---|
| Frontend и backend | Выполнено | Vue SPA обращается к FastAPI по относительному `/api/v1` |
| PostgreSQL | Выполнено | PostgreSQL 18.3 во всех Compose-контурах и интеграционных тестах |
| CRUD сущностей | Выполнено | Полный CRUD категорий, моделей, сотрудников и оборудования |
| Выдача, возврат и история | Выполнено | Отдельные REST-операции, неизменяемая история и повторяемый возврат |
| HTTP/REST, HTTP/1.1 | Выполнено | Nginx proxy и FastAPI; smoke-запрос получил `HTTP/1.1 200 OK` |
| Нересурсоёмкий стек | Выполнено | При простое: API около 75 MiB на реплику, Nginx 7 MiB, PostgreSQL 33 MiB |
| Понимание приложения | Выполнено | Предметная область, БД, диаграммы, архитектура и дизайн-система находятся в `docs/` |

## 12 Factor

| Фактор | Статус | Реализация и проверка |
|---|---|---|
| I. Codebase | Выполнено | Один Git-репозиторий содержит код, миграции, инфраструктуру и документацию |
| II. Dependencies | Выполнено | `uv.lock`, `package-lock.json`, фиксированные версии базовых образов; чистая контейнерная сборка прошла |
| III. Config | Выполнено | Порты, БД, пулы и тайм-ауты приходят из env; production требует пароль, секретов в Git нет |
| IV. Backing services | Выполнено | PostgreSQL подключается через env и внутреннее DNS-имя Compose |
| V. Build/release/run | Выполнено | Multi-stage образы неизменяемы; конфигурация добавляется при запуске; миграция — отдельный release-процесс |
| VI. Processes | Выполнено | API не хранит состояние локально; пользовательские данные пережили перезапуск двух реплик |
| VII. Port binding | Выполнено | Uvicorn слушает 8000, Nginx 8080; наружу опубликован только localhost-порт frontend |
| VIII. Concurrency | Выполнено | Две реплики API одновременно работали с общей БД; блокировки и UNIQUE проверены интеграционными тестами |
| IX. Disposability | Выполнено | Uvicorn получил SIGTERM, выполнил application shutdown и закрыл пул; лимиты 20/30 с настроены |
| X. Dev/prod parity | Выполнено | Development, tests и production используют PostgreSQL 18 и те же миграции; SQLite отсутствует |
| XI. Logs | Выполнено | API и Nginx пишут в stdout/stderr; API-журналы содержат request ID, маршрут, статус и длительность |
| XII. Admin processes | Выполнено | `migrate` и `seed` запускаются отдельными процессами того же backend-образа |

## Приёмочные доказательства

- Backend: 17 pytest-тестов на настоящей PostgreSQL, включая контролируемые гонки.
- Frontend: TypeScript, ESLint, 4 Vitest-теста и production-сборка.
- Browser: 5 Playwright-сценариев CRUD, выдачи/возврата, истории, навигации,
  конфликтов и сетевой ошибки.
- Production: два непривилегированных API-процесса, непривилегированный Nginx,
  отдельная миграция, прямое открытие `/equipment/1`, request ID и HTTP/1.1.
- Отказ БД: `/health/live` вернул 200, `/health/ready` — 503; после возврата БД
  readiness восстановился.
- Перезапуск: созданная проверочная запись осталась в PostgreSQL.

Измерение ресурсов является одиночным локальным наблюдением, а не SLO и не
нагрузочным тестом. Авторизация отсутствует по границе MVP, поэтому окружение следует
оставлять закрытым; это не препятствует соответствию учебному заданию.
